教师课前准备

这堂课用 30 分钟讲清楚 Tobi 怎样检测触摸、显示表情，以及怎样用两只舵机让头部转动。先看接线和固件，再拆看头盔的三个原有零件，最后在 Velxio 里演示点头和摇头。打开课堂讲义

备齐两个工程和三个模型

  1. 解压学生课程包。基础工程是 simulation/tobi-original.vlx，可以用它讲单击、双击和眼睛的变化。需要读代码时，打开 firmware/original/original.ino。学生课程包
  2. 打开 3d-models/，依次看 Helmet1.stl、Core .stl、Core 2.stl。课堂页提供三个单件模型和头壳与底板的分解视图。小折板的安装用途尚无作者说明。原项目的三个零件
  3. 另存一份双舵机课堂工程。它在 Velxio 里使用经典 ESP32 DevKit V1，编辑器能显示两只舵臂的转动。课程实物使用 ESP32-C3，烧录时选 C3 固件。要现场演示改代码，请让 coding agent 打开草图的工作副本。双舵机画布工程 · C3 实物固件

在教室电脑上排演

在官方编辑器中依次打开基础工程和双舵机工程。两次都从文件区点 Open project，选择下载的 .vlx 文件，再点 Load → Run。看到串口的 TOBI READY 后再按绿色 Touch 按钮。导入下一个工程前先保存当前修改。打开 Velxio 官方编辑器 · 仿真操作步骤

课堂时间 演示动作和可指给学生看的结果
0–14 分钟 从实物照片和基础回放开始。在接线图上从 TTP223 的 OUT 找到 GPIO10，再找开发板到 OLED 的两根线。对照单击、双击的工作原理图与代码，指出第一次松手后等 400 毫秒的原因。单击显示笑眼，双击出现泪滴，约 3 秒后恢复普通眼睛。
14–18 分钟 先展示三个原项目的零件，再切到「从底部分解」。用面窗解释 OLED 显示面的朝向，用头顶内壁解释触摸电极朝向，从底部开口看主板、插头和走线需要的空间。
18–22 分钟 在双舵机画布上输入一次单击和一次双击。单击时上方橙色舵臂偏转后回中。双击时下方蓝色舵臂向两边摆动后回中。对照三维头架，指出点头时转动的头盔和摇头时一起转动的 U 形架。
22–26 分钟 在经典 ESP32 画布上把两根信号线追到 GPIO25、26，再对照课程实物 C3 的 GPIO5、6。找到两轴回中的 1500 微秒命令，说明外部舵机电源怎样与开发板共地。
26–30 分钟 将点头偏移从 80 改为 60 微秒。在 Velxio 重新编译，单击查 GPIO25=1560us，双击查 GPIO26 的三个目标有没有变化。最后从 OLED 和两只舵臂再核对一次。

若课堂电脑无法运行仿真，讲义中有基础表情回放和双舵机画布实录。结构部分可以用网页里的模型，也可在切片器里逐件打开 STL。录屏用于讲解预先运行过的程序，学生修改的草图仍需重新编译测试。双舵机实录

在教学电脑上运行 Velxio 服务

如果要用网页里的三维头架实时运行 C3 固件，或用课程脚本在本机编译，需在演示用的电脑上启动 Velxio。127.0.0.1 指向打开网页的那台电脑。

在已经配置过的备课电脑上，先启动 Docker Desktop，再运行 docker start desk-pet-velxio。在浏览器打开本机编辑器，确认课前已能导入并运行工程。本机 Velxio 编辑器

在新电脑上，先安装 Docker，再运行下面的命令创建容器。命令使用课程测试过的镜像，端口仅监听本机。首次下载需要时间，宜在上课前完成。以下写法适用于 macOS 或 Linux，在 PowerShell 中可去掉续行符，合为一行执行。Velxio 项目说明

docker run -d --pull=missing --name desk-pet-velxio \
  -p 127.0.0.1:3080:80 \
  -e VELXIO_NEWS=off \
  -v desk-pet-velxio-data:/app/data \
  -v desk-pet-velxio-arduino:/root/.arduino15 \
  -v desk-pet-velxio-libs:/root/Arduino \
  -v desk-pet-velxio-ccache:/var/cache/ccache \
  -v desk-pet-velxio-build:/var/lib/velxio-build \
  ghcr.io/davidmonterocrespo24/velxio@sha256:2f3c65c4ce11fc681e79758fa6edce43f7b5d052b2922b1d8ae570794792aeef

课后制作

制作能动的头架，要准备两只位置舵机和能承担两轴负载的独立电源。安装舵盘前先单独让舵机回中，再断电装配，逐轴检查运动方向、线束余量和带动头部时的供电。需要更短的练习时，可选表情时长或 OLED 支架。双舵机实物练习 · 表情时长练习 · 头盔支架与试片

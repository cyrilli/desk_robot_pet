6. 为 Tobi 头盔设计配件

给 Tobi 加一个零件，可以保留课程包里的头盔外形。名牌只需要与外表面配合，屏幕支架还要同时对准面窗和电路板。这两个例子需要提供给 coding agent 的尺寸不同。

头壳、底板和小折板

在查看器中分别打开课程包的三个 STL。转动 Helmet1.stl，找到正面的面窗和底部开口。再看 Core .stl，底板两侧各有一根立架。第三个文件 Core 2.stl 是小折板，项目资料没有标明它固定的器件。单独打开模型查看器

STL 用三角形保存零件表面。可以量出面窗有多宽，却很难像修改设计草图那样单独改它的宽度。整体放大头壳会连安装空间一起放大。3MF 还可保存单位、材料等信息，能否修改孔径、壁厚等参数，取决于是否有可编辑的设计源文件。

用 OpenSCAD 改名牌

将名牌源码放到工作副本的 3d-models/ 中。OpenSCAD 用代码描述零件，pet_name 决定文字，plate_w、plate_h 和 plate_t 分别决定底牌的宽、高、厚。可以把以下要求交给 coding agent。下载名牌源码

请用 3d-models/nameplate.scad 另存一份名为 MIKA 的名牌。
底牌宽 32 mm、高 12 mm、厚 2 mm，字面比底牌高出 0.8 mm。
保留平整的底面，给出可编辑源文件和打印用的 STL。

在 OpenSCAD 打开修改后的源码，按 F5 预览。看文字是否落在底牌内，再按 F6 渲染，通过 File → Export → Export as STL 导出。确定名牌在头盔上的位置时，检查它是否遮挡屏幕、触摸区或底板的拆卸位置。MIKA 示例源码 · MIKA 示例 STL

测量屏幕、触摸模块和开发板

把尺寸表保存为 3d-models/enclosure-measurements.txt，以毫米记录每个尺寸。注明数值来自 STL 还是实物，未量过的填“待测”。下载尺寸记录表

测量部位 测量方法与用途
面窗和底部开口 以面窗中心和下沿为基准，量到立架和底板的距离。再沿支架装入的方向量最窄处。
OLED 分别量亮屏区域和整块电路板（PCB）。前者用来对准面窗，后者决定支架宽度。标出能托住的空白板边，并量出插好导线后的总深度。
TTP223 记录感应电极在哪一面、头顶的触摸位置和壁厚。拿同材料、同厚度的试片盖住电极，实际试一次单击和双击。
ESP32-C3 插上要用的 USB 线，测量插头外壳、排针和弯曲的导线占用的空间。检查底板能否连同接线一起取出。

请 coding agent 设计屏幕支架

屏幕支架要让亮屏区域居中，还要能从底部装进头壳。把记录表和课程包的模型放在同一项目中，再给助手这段要求。

请读 3d-models/enclosure-measurements.txt，以 Helmet1.stl 和 Core .stl 为参照。
为我的 OLED 设计可拆的内支架，让显示区对准面窗，用支架托住 PCB 的空白板边。
说明支架从哪里装入，靠什么定位，还有哪些尺寸需要我实测。
尺寸齐备后，另存 3d-models/helmet-oled-mount.scad。
给出一段可单独打印的局部试片，用来检查板边配合和窗口位置。

按 F5 预览，沿实际装入方向检查支架能否穿过壳体开口。按 F6 渲染，分别导出试片和支架，用切片器重新打开 STL 并核对尺寸。先打印试片，用同一块 OLED 检查板边能否放入，插上线之后还能否对准面窗。课堂中的器件布局

方形外壳的窗口尺寸练习

方形外壳示例有三组 PCB 导槽。下载源码，在工作副本中保存为 3d-models/my-case.scad。打开分解视图和剖面视图，找到屏幕从哪侧装入。方形外壳源码 · 四个装配视图

假设屏幕试装后，显示区左右各被挡住 0.5 mm。窗口原宽 22 mm，要保留中心位置，两边各放宽 0.5 mm。可以这样要求助手修改。

请修改 3d-models/my-case.scad，把 window_w 从 22 mm 调为 23 mm。
保留窗口中心、PCB 导槽和触摸区的位置。显示上盖内侧的预览，
重新导出窗口试片，列出修改前后的尺寸。

在 OpenSCAD 的 part 参数中选择 coupon，按 F6 渲染并导出试片。切片后，检查窗口边缘和导槽是否都有连续的打印路径，再用同一块屏幕试装。要导出底壳和上盖，分别选择 base 和 lid。示例模型的窗口与导槽试片
